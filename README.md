# ブロックブラスト・究極パズル

ブロックブラスト風のパズルゲームです。

## 📁 ファイル構成

```
ブロックブラスト風/
├── index.html              # メインHTMLファイル
├── README.md              # このファイル
├── css/
│   └── style.css         # すべてのスタイル定義
└── js/
    ├── config.js         # ゲーム設定・定数
    ├── audio.js          # 音声システム
    ├── render.js         # 描画ロジック
    ├── game.js           # ゲームロジック
    └── main.js           # メイン処理・インタラクション
```

## 🎮 ゲームモード

### CLASSIC（クラシック）
- 無限モード
- スコアを競う
- コンボシステム搭載

### ADVENTURE（アドベンチャー）
- 50個の図形を完成させるチャレンジモード
- 特定のパターンを収集

## 🎯 遊び方

1. ホーム画面でモードを選択
2. 下部に表示される3つのブロックから1つを選択
3. ドラッグして10×10のグリッドに配置
4. 行または列が埋まると消える
5. すべてのブロックが配置できなくなるとゲームオーバー

## 🔧 技術スタック

- **HTML5 Canvas** - ゲーム描画
- **Vanilla JavaScript** - ゲームロジック
- **Tone.js** - 音声システム
- **CSS3** - スタイリング

## 📝 コード構成の詳細

### config.js
- ゲームボードのサイズ（10×10）
- ブロックの形状定義
- 煽りメッセージ
- カラーテーマ

### audio.js
- 効果音の再生
- BGMシステム
- 音声のオン/オフ切り替え

### render.js
- ブロックの描画
- グリッドの描画
- ゴーストプレビュー
- ピース選択エリアの描画

### game.js
- ゲーム状態管理
- ピース配置ロジック
- 行/列の消去判定
- スコア計算
- ゲームオーバー判定

### main.js
- ドラッグ＆ドロップ処理
- ゲーム初期化
- UIコントロール
- イベントハンドリング

## 🎨 カスタマイズ

### ブロックの色を変更
`js/config.js`の`THEME.colors`配列を編集

### グリッドサイズを変更
`js/config.js`の`ROWS`と`COLS`を編集

### 煽りメッセージを変更
`js/config.js`の`TAUNTS`オブジェクトを編集

## 🚀 起動方法

1. `index.html`をブラウザで開く
2. モードを選択してプレイ開始

## 📱 対応環境

- モダンブラウザ（Chrome, Firefox, Safari, Edge）
- デスクトップ＆モバイル対応
- タッチ操作対応

## 🎵 音声について

- 初回クリック時に音声システムが初期化されます
- 設定から音声とBGMを個別にオン/オフできます
